# Unfollowers

a chrome extension to see who doesn't follow you back on instagram.

## usage
- open instagram in your browser
- click the extension icon
- it scrapes your following list and shows non-reciprocators
- search, whitelist, batch unfollow with speed control
- export to csv / json

## dev
```bash
npm run dev
```
`npm run build` builds the extension to `out/`.

built with svelte, vite, and tailwind v4.
